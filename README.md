# Wizard-Game
A top-down style game where a wizrd has to collect all the potion which are hidden to win.

# Tech used
html, css, js

# Motivation for building this/Why build this
Who wouldnt want to build a game.

# How to play
Use arrows or wasd to move the wizard and find the hidden potions and and dont let enemy caught you if enemy caught you the game is over.
